# my-first-site

钟奕生的第一个网页项目，也是个人作品集的入口。

## 这是什么

一个纯静态的个人主页。没有后端、没有数据库、不需要安装任何东西。

**在线地址**：https://zhongyisheng.github.io/my-first-site/

## 文件说明

| 文件 | 作用 | 类比 |
|---|---|---|
| `index.html` | 页面的内容和结构 | 骨架 |
| `style.css` | 颜色、间距、布局、屏幕适配 | 皮肤 |
| `script.js` | 主题切换、记住用户选择 | 肌肉 |
| `assets/` | 每个作品的页面截图 | 相册 |
| `README.md` | 就是这个说明文件 | 说明书 |

## 怎么在本地打开

**方法一（最简单）**：双击 `index.html`，浏览器直接打开。

**方法二（更专业）**：在项目文件夹里开终端，输入：

```bash
python -m http.server 8000
```

然后浏览器访问 `http://localhost:8000`。

> 方法二的意义：双击打开用的是 `file://` 协议，有些功能（比如读取本地数据）会被浏览器限制。用本地服务器是 `http://`，行为跟真实网站一致。

## 怎么验收（改完东西一定要做）

1. 浏览器打开页面 → 能看到内容、颜色正常 = 骨架和皮肤没问题
2. 点「切换主题」按钮 → 颜色变了 = JS 在跑
3. 刷新页面 → 主题保持 = localStorage 记住了
4. 按 F12 → 看 Console 有没有红色报错 → 没有 = 干净
5. 把浏览器窗口拖窄 → 文字不挤、自动换行 = 手机适配生效

**任何一条不对，就是没做成。**

## 作品截图怎么更新

`assets/` 里的五张截图不是手工截的，是脚本自动截的：

```bash
node D:\Code\outputs\shots.mjs             # 全部重截
node D:\Code\outputs\shots.mjs snake-game  # 只重截一个
```

脚本会遥控浏览器逐个打开作品，**该等数据就等、该点按钮就点**，再截图：

| 作品 | 截图前做了什么 | 为什么 |
|---|---|---|
| 待办清单 | 往浏览器里塞 5 条待办，再刷新 | 空白浏览器打开就是空列表，拍下来是"还没有待办" |
| 贪吃蛇 | 点一下「重新开始」 | 没人操作的浏览器里蛇会撞墙，拍下来是"游戏结束" |
| 留言板 | 等"正在从云端读取"消失 | 否则拍到的是一句加载中 |
| 报错翻译官 / 自动化 | 等页面稳定 | — |

**为什么要脚本**：命令行直接截图是"打开就按快门"，页面还没准备好就被拍进去了。这个脚本改成了"能等、能点、能预置数据"再拍。
